# Git Collaboration Workflow

This repository demonstrates a collaborative Git workflow using feature branches, pull requests, code reviews, and trunk-based development.

## Project Goals

- Create and manage short-lived feature branches
- Submit changes through pull requests
- Perform collaborative code reviews
- Apply reviewer suggestions before merging
- Demonstrate trunk-based development
- Control a release feature using a feature flag

## Current Feature

The new collaboration workflow feature is currently under development.
